# Activity Squish UAT

## Shorten first, lengthen second

1. Press the border between two activities.
2. Drag up.
3. Release pointer.
   - Check that the first activity is shorter.
   - Check that the second activity is longer and starts when the first one ends.
   - Check that no other activities have changed.

## Lengthen first, shorten second

1. Press the border between two activities.
2. Drag down.
3. Release pointer.
   - Check that the first activity is longer.
   - Check that the second activity is shorter and starts when the first one ends.
   - Check that no other activities have changed.

## Snap

1. Press the border between activitivities.
2. Drag to the left side where hour markers are.
   - Check that the border snaps to the hour that is closest to the pointer coordinates.
3. Release pointer.
